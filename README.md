# HR Insights Dashboard (Tableau)

An HR analytics dashboard built in **Tableau**, analyzing employee performance, absences, engagement, salary distribution, and workforce diversity across departments.

> **Note:** Built independently as part of the ITI Data Analytics Training Program.

## 📊 Dataset Overview

- **Total Employees:** 311
- **Departments:** Production (209), IT/IS (50), Sales (31), Software Engineering (11), Admin Offices (9), Executive Office (1)
- **Active vs Terminated:** 207 active employees, 104 terminated
- **Gender Split:** 176 female, 135 male

## 🔍 Key Dashboard Views

### 1. Absence vs Performance
Cross-analysis between employee absence rates and performance scores to identify patterns between attendance and productivity.

### 2. Average Absences by Department
Departmental breakdown of absence rates to highlight operational risk areas.

### 3. Average Salary by Department
Salary distribution analysis across departments to support compensation benchmarking.

### 4. Employee Count by Performance Level
Workforce distribution across 4 performance tiers:
- **Fully Meets:** 243 employees (78%)
- **Exceeds:** 37 employees (12%)
- **Needs Improvement:** 18 employees (6%)
- **PIP (Performance Improvement Plan):** 13 employees (4%)

### 5. Engagement & Diversity Analysis
Insights into employee engagement survey scores and workforce diversity metrics (citizenship status, Hispanic/Latino representation, diversity job fair hires).

## 🛠️ Tools & Skills Used

- **Tableau:** Dashboard design, calculated fields, action filters, parameter controls
- **Data Source:** HRDataset_v14.csv (311 employee records across 6 departments)
- **Analysis Focus:** HR performance management, workforce diversity, compensation analysis
